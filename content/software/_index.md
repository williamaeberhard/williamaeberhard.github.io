#### [manateessm](https://github.com/williamaeberhard/manateessm)

R code for fitting the manatee counts state space model, supplementary material to [Scolardi, Wilkinson, and Aeberhard (2025)](https://williamaeberhard.github.io/publications/scolardi_et_al_2025/)


#### [EagleRayGrowth](https://github.com/williamaeberhard/EagleRayGrowth)

R code for estimating the von Bertalanffy growth parameters from mark-recapture data, as well as comparing two populations (e.g. wild and aquarium) in terms of their growth parameters, supplementary material to [Boggio-Pasqua, Bassos-Hull, Aeberhard, Hoopes, Swider, Wilkinson, and Dureuil (2022)](https://williamaeberhard.github.io/publications/boggiopasqua_et_al_2022/)


#### [GrowthEstimation](https://github.com/williamaeberhard/growthestimation)

R code for various estimation methods of von Bertalanffy growth parameters, supplementary material to [Dureuil, Aeberhard, Dowd, Pardo, Whoriskey, and Worm (2022)](https://williamaeberhard.github.io/publications/dureuil_et_al_2022_growth/)


#### [RobSSM](https://github.com/williamaeberhard/robssm)

R code for robust estimation for state space models, supplementary material to [Aeberhard, Cantoni, Field, Kuensch, Mills Flemming and Xu (2021)](https://williamaeberhard.github.io/publications/aeberhard_et_al_2021_robssm/)


#### [spglmetm](https://github.com/williamaeberhard/spglmetm)

R package for fitting of semi-parametric generalized linear models based on exponentially tilted mixtures


#### [SSM-SeaScallops](https://github.com/williamaeberhard/SSM-SeaScallops)

R code for simulating and fitting the alternative state space model of [Yin, Aeberhard, Smith and Mills Flemming (2019)](https://williamaeberhard.github.io/publications/yin_et_al_2019/)


#### [trNB](https://github.com/williamaeberhard/trnb)

Fully-documented R package for truncated negative binomial and truncated Poisson family objects


#### [robNB](https://github.com/williamaeberhard/robnb)

Fully-documented R package for robust estimation and accurate inference for the negative binomial model, implementing the methods presented in [Aeberhard, Cantoni and Heritier (2017)](https://williamaeberhard.github.io/publications/aeberhard_et_al_2017/)


#### [glmrob.nb](https://github.com/williamaeberhard/glmrob.nb)

R code for fitting a robust negative binomial generalized linear model, supplementary material to [Aeberhard, Cantoni and Heritier (2014)](https://williamaeberhard.github.io/publications/aeberhard_et_al_2014/)
